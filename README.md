# Povos Indígenas — Equipe 7

Apresentação interativa em HTML/CSS/JS sobre os povos indígenas no Brasil.

## Como abrir

Basta abrir o arquivo `index.html` em qualquer navegador (Chrome, Edge, Firefox).
Para usar no projetor da escola, dê play em tela cheia (F11).

Se quiser publicar no GitHub Pages: `Settings > Pages > Deploy from branch > main / root`.

## Como navegar

- **Avançar:** seta para a direita (→) ou Enter
- **Voltar:** seta para a esquerda (←) ou barra de espaço
- No celular: deslize o dedo para os lados ou use os botões no rodapé

## Estrutura

```
povos-indigenas/
├── index.html          → estrutura dos 8 slides
├── assets/
│   ├── style.css        → visual (cores, tipografia, animações)
│   ├── script.js         → navegação e animação da roleta
│   ├── topics.js         → texto dos 6 focos sobre os povos indígenas
│   └── img/              → fotos usadas na animação da roleta
└── README.md
```

## Sobre a roleta

A cada slide de 2 a 7, uma roleta gira e sorteia um dos focos do trabalho
(sem repetir os que já caíram), enquanto um integrante da equipe "entra"
na cena para girá-la. O último giro usa um quadrado preto no lugar da
foto, representando o Jonas.

Os focos sorteados: quem são os povos indígenas, onde vivem, como vivem,
cultura, desafios atuais e o legado deixado para o Brasil.
